OfferTrack v2.0.0 - 快速使用说明
=================================

OfferTrack 是一个 Microsoft Edge 秋招投递管理插件。
它可以解析招聘官网投递记录、同步到飞书多维表格，并定时自动跟进仍在进行中的招聘流程。

一、安装插件
------------
1. 解压 OfferTrack_Edge_v2.0.0.zip。
2. Edge 打开：edge://extensions/
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择 OfferTrack_Edge_v2.0.0 文件夹。

如果从旧版升级，推荐覆盖原插件目录后，在 edge://extensions/ 点击“重新加载”，通常可以保留原有飞书设置。

二、创建飞书应用
--------------
1. 打开飞书开放平台：
   https://open.feishu.cn/app?lang=zh-CN
2. 创建“企业自建应用”，名字可填 OfferTrack。
3. 在“凭证与基础信息”复制 App ID 和 App Secret。
4. 在“权限管理”中以“应用身份”开通多维表格读写权限，推荐 bitable:app。
5. 如果使用 /wiki/ 多维表格链接，再开通 wiki:node:read。
6. 如果飞书要求发布版本，到“版本管理与发布”中发布新版本。

三、创建飞书多维表格
------------------
1. 新建一个多维表格，例如“2027届秋招投递记录”。
2. 打开多维表格右上角菜单，找到“添加文档应用”。
3. 添加刚创建的 OfferTrack 应用，并给它编辑权限。
4. 复制多维表格完整链接。

四、配置 OfferTrack
-----------------
1. 打开 OfferTrack → 设置。
2. 填 App ID / App Secret。
3. 粘贴多维表格链接。
4. 点击“从链接解析”。
5. 点击“测试连接”。
6. 点击“初始化表头”。
7. 点击“保存设置”。

五、日常同步
----------
1. 打开招聘官网“我的投递 / 投递记录 / 我的申请”等页面。
2. 页面右下角会出现 OfferTrack 小图标和识别数量。
3. 点击小图标查看解析结果。
4. 确认公司、岗位、地点、时间、状态正确后同步到飞书。

六、开启自动跟进
--------------
在设置页找到“自动跟进招聘进度”：

推荐：
- 开启自动跟进
- 检查间隔：6 小时
- 模式：安全模式
- 开启“状态变化时通知”

安全模式只检查你当前 Edge 已经打开并登录的招聘网站。

如果希望插件在页面没打开时也尝试检查，可以选择：
“实验模式：必要时后台打开标签页检查并自动关闭”。

实验模式不会自动填写手机号/验证码，也不会绕过验证码或网站风控；登录失效时只会在飞书记录“需要登录”。

七、手动立即检查
--------------
插件 Popup 或设置页点击“立即跟进全部”。
OfferTrack 会从飞书读取仍在进行中的投递并开始检查。

默认不检查 Offer / 已结束 / 已撤回记录。
如果某条记录不想自动检查，可在飞书“自动跟进”字段填写：关闭
