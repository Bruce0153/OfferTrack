OfferTrack - 快速使用说明
=========================

OfferTrack 是一个 Microsoft Edge 秋招投递管理插件。
打开招聘网站的“我的投递 / 投递记录 / 应聘记录 / 我的申请”等页面后，插件会自动解析公司、岗位、地点、投递时间和状态，并可以一键同步到飞书多维表格。


一、安装 Edge 插件
-----------------
1. 解压 OfferTrack_Edge_v1.6.0.zip。
2. Edge 地址栏打开：edge://extensions/
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择 OfferTrack_Edge_v1.6.0 文件夹。
6. 建议把 OfferTrack 固定到 Edge 工具栏。


二、创建飞书自建应用
-------------------
1. 打开飞书开放平台：
   https://open.feishu.cn/app?lang=zh-CN

2. 登录后进入“企业自建应用”。
3. 点击“创建企业自建应用”。
4. 应用名称可填写：OfferTrack。
5. 创建后进入“凭证与基础信息”。
6. 复制 App ID 和 App Secret，填写到 OfferTrack 设置中。

注意：App Secret 相当于应用密码，不要公开。


三、开通权限
-----------
进入飞书应用：开发配置 → 权限管理。

推荐在“应用身份”下开通：

1. 查看、评论、编辑和管理多维表格
   Scope：bitable:app

2. 如果你的多维表格链接是 /wiki/ 开头，再开通：
   查看知识空间节点信息
   Scope：wiki:node:read

如果权限状态显示“待发布”，进入“版本管理与发布”发布新版本。


四、创建飞书多维表格
-------------------
1. 在飞书中新建一份多维表格，例如：2027届秋招投递记录。
2. 不需要自己创建全部表头。
3. 复制浏览器地址栏中的完整多维表格链接。

OfferTrack 支持：
- https://xxx.feishu.cn/base/...
- https://xxx.feishu.cn/wiki/...


五、添加文档应用（非常重要）
--------------------------
打开目标多维表格：

右上角 ... → ...更多 → 添加文档应用

1. 搜索 OfferTrack。
2. 添加应用。
3. 给应用编辑权限。
4. 如果多维表格启用了高级权限，建议给 OfferTrack“可管理”权限。

如果搜索不到应用，请确认：
- 已开通 bitable:app 等多维表格 API 权限；
- 权限已经生效；
- 如飞书要求，应用版本已经发布；
- 应用可用范围包含该文档所有者。


六、连接 OfferTrack 与飞书
-------------------------
打开 OfferTrack → 设置。

填写：
- App ID
- App Secret
- 多维表格完整链接

然后依次点击：
1. 从链接解析
2. 测试连接
3. 初始化表头
4. 保存设置

插件会自动解析 App Token 和 Table ID，并创建秋招投递管理所需字段。


七、日常使用
-----------
1. 打开招聘网站的投递记录页面。
2. 等待页面加载约 1～3 秒。
3. 页面右下角会出现一个小 OfferTrack 图标和解析数量。
4. 小面板默认不会自动弹出。
5. 点击右下角图标才会展开同步面板。
6. 点击 × 后面板会收起，不会因为网页动态刷新再次自动弹出。
7. 也可以点击 Edge 工具栏中的 OfferTrack 查看完整预览。
8. 检查公司、岗位、地点、投递时间、状态后，点击“同步到飞书”。
9. 同步成功后页面面板会自动收起。

OfferTrack v1.6.0 会优先读取招聘网页自身提供的 JobPosting、hiringOrganization、JSON-LD、application/json、Next/Nuxt 初始化状态，以及常见 companyName / jobTitle / positionName 等底层字段，再结合页面可见内容进行校验。


飞书表格主要字段
---------------
公司 / 岗位名称 / 工作地点 / 投递时间 / 当前状态 / 招聘平台 / 岗位链接 /
最近更新时间 / 下一步行动 / 面试时间 / 优先级 / 备注 / 唯一记录ID / 原始状态


常见错误
-------
- 缺少 wiki:node:read：使用了 /wiki/ 链接，回飞书开放平台开通知识库节点读取权限。
- 缺少 bitable:app：开通“查看、评论、编辑和管理多维表格”，并确认是应用身份权限。
- 权限已开但无法写入：检查多维表格“添加文档应用”，确保 OfferTrack 已加入并有编辑/可管理权限。
