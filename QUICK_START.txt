OfferTrack v1.5.0 简要使用说明
===============================

安装：
1. 解压 OfferTrack_Edge_v1.5.0.zip。
2. 打开 Edge：edge://extensions/
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择 OfferTrack_Edge_v1.5.0 文件夹。

升级且希望尽量保留当前配置：
- 如果你之前加载的是一个固定文件夹，可以把 v1.5.0 文件覆盖到原插件文件夹，再在 edge://extensions/ 点击“重新加载”。
- 如果直接移除旧扩展并从新目录重新加载，Edge 可能把它视为新的解压缩扩展，需要重新填写飞书配置。

首次设置飞书：
- 填 App ID / App Secret
- 粘贴飞书多维表格 /base/ 或 /wiki/ 链接
- 点击“从链接解析”
- 点击“测试连接”
- 点击“初始化表头”
- 点击“保存设置”

日常使用：
1. 打开招聘官网“我的投递 / 投递记录 / 我的申请”等页面。
2. 页面加载完成后等待约 1~3 秒。
3. 点击 OfferTrack 图标。
4. 检查预览中的：公司、岗位、地点、投递时间、状态。
5. 确认正确后点击“同步到飞书”。

v1.5.0 的通用保护：
- “数据与算法类 / 研发-算法 / 通用智能板块”等职类信息不作为岗位。
- “专场招聘会投递”等导航不作为投递记录。
- “应届 / 校招 / 板块”等不作为公司名。
- “录用评估”只是流程阶段，不自动等于 Offer。
- 若卡片明确显示“已结束/未通过”等，优先同步为“已结束”。

注意：旧版已写入飞书的错误/重复记录不会自动删除。
