OfferTrack v2.2.0 - 快速使用说明
=================================

OfferTrack 是一个 Microsoft Edge 秋招投递管理插件，可以解析招聘官网投递记录、同步到飞书多维表格，并自动跟进仍在进行中的招聘流程。

一、安装插件
------------
1. 解压 OfferTrack_Edge_v2.2.0.zip。
2. Edge 打开：edge://extensions/
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择 OfferTrack_Edge_v2.2.0 文件夹。

二、飞书配置
------------
1. 打开 https://open.feishu.cn/app?lang=zh-CN
2. 创建企业自建应用，例如 OfferTrack。
3. 在“凭证与基础信息”复制 App ID / App Secret。
4. “权限管理”中以应用身份开通 bitable:app；Wiki 多维表格再开 wiki:node:read。
5. 如提示权限待发布，在“版本管理与发布”发布新版本。
6. 创建飞书多维表格，在右上角菜单选择“添加文档应用”，添加 OfferTrack 并给编辑权限。
7. 在插件设置中粘贴多维表格链接，依次点击：从链接解析 → 测试连接 → 初始化表头 → 保存设置。

三、日常同步
------------
打开招聘官网“我的投递 / 投递记录 / 我的申请”等页面，点击右下角 OfferTrack 小图标检查解析结果，再同步到飞书。

四、自动跟进
------------
推荐设置：
- 开启自动跟进
- 检查间隔：6 小时
- 安全模式
- 开启“优先尝试安全 GET API”
- 开启“读取页面 Structured State”
- 开启状态变化通知

v2.2 自动检查顺序：
API GET → Structured State → Page Scan

API GET 只尝试同源、只读、明显属于投递查询的地址；失败会自动降级。Structured State 读取页面 JSON/SSR Store；仍无法确认时使用原有 DOM/Semantic Parser。

只有与飞书现有岗位高置信匹配的结果才允许更新状态。登录失效、验证码、API 失败、结构化数据不完整、岗位匹配不足时都不会覆盖原状态。

飞书自动跟进字段会包含：招聘系统、检查方式、最后检查时间、检查状态、登录状态、最近错误等。
