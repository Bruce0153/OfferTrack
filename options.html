🎯 OfferTrack 设置

第一次只需配置一次飞书，之后打开投递页即可使用。

1. 飞书应用

建议只使用你自己的飞书企业自建应用。OfferTrack 会限制本地设置只由扩展的可信页面/后台读取；App Secret 只用于向飞书开放平台换取访问令牌。

2. 多维表格

Wiki 链接会自动调用飞书“获取知识空间节点信息”接口换取真实 App Token，因此需要应用具有“查看知识库”权限。

3. 使用方式

4. 自动跟进招聘进度

v2.2 按 API GET → Structured State → Page Scan 三级策略检查。API 只尝试同源、明确属于投递查询且不含提交/撤回/修改等动作的 GET 地址；只有高置信匹配当前飞书岗位时才采用结果。失败会自动降级，不会覆盖原状态。实验后台标签页模式仍只复用 Edge 已有登录会话。

5. 公司名覆盖（可选）

如果某个招聘官网没有稳定暴露中文品牌名，可以按域名固定公司展示名。这不是站点 Adapter，只覆盖最终公司名称。

高级：特殊网站 CSS Selector

通用解析失败时使用。域名示例：jobs.example.com。卡片选择器必填，其余可按需填写。
