🎯 OfferTrack 设置

第一次只需配置一次飞书，之后打开投递页即可使用。

1. 飞书应用

App Secret 默认保存在浏览器会话内存中，浏览器重启后需重新输入；开启“记住”后才会写入本机扩展私有存储。无论哪种方式都不会发送到招聘网站、飞书表格或日志。

2. 多维表格

Wiki 链接会自动调用飞书“获取知识空间节点信息”接口换取真实 App Token，因此需要应用具有“查看知识库”权限。

工作方式与隐私

Cookie 会话证据 → 安全 GET API → Structured State → Page Scan

Cookie 只用于本机判断会话是否可能有效和登录恢复，不保存 Cookie 值；没有 Cookie 也不会直接判定掉线，页面仍会继续兜底。GET API 仅同源、只读；Structured State 只读取有界 JSON / SSR Store，不执行远程代码。

5. 公司名覆盖（可选）

如果某个招聘官网没有稳定暴露中文品牌名，可以按域名固定公司展示名。这不是站点 Adapter，只覆盖最终公司名称。

高级：特殊网站 CSS Selector

通用解析失败时使用。域名示例：jobs.example.com。卡片选择器必填，其余可按需填写。

隐私：插件不保存招聘网站账号密码、Cookie 值或验证码。Cookie API 仅在本机读取会话证据并立即摘要为数量/健康等级；不会写入飞书、日志或持久化原始 Cookie。
